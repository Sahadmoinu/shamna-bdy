# Shamna K — Portfolio

Personal portfolio for Shamna K, Project Coordinator & Business Analyst.

Built with React 19, Vite, Tailwind CSS v4 and Framer Motion.

## Run

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

## Editing content

All text (experience, projects, skills, contact links) lives in `src/data.js`.
The portrait is `public/shamna.jpg`.
